## Products

### [Hotfix](https://hotfix.cc)

A crowdsourced pothole reporting platform, live in production. Citizens can report potholes with photos and location, vote on reports, and explore them on a map.

**Built with:** Next.js · Node.js · AWS Lambda · MongoDB · Amazon Cognito · Cloudflare

### [Scouting Beavie](https://github.com/aryanchari06/scouting-beavie-frontend)

An AI-powered Chrome extension that scans webpages for job openings, matches them against your resume, and scores your fit for each role. Currently being published to the Chrome Web Store.

**Backend:** AWS SAM · AWS Lambda · API Gateway · DynamoDB · rate limiting
